# STRATAON SNMP MIBs

Official SNMP Management Information Base (MIB) definitions for STRATAON devices.

This repository provides the official MIB files required to monitor and integrate
STRATAON products with SNMP-compatible network management and monitoring systems.

## Supported Products

STRATAON MIB definitions may include support for products such as:

- sentiaMAN
- sentiaPRO
- miniENV
- smartPDU

Support varies according to product model and firmware version.

## Integration

The MIB files provided here can be used with standard SNMP monitoring platforms,
including:

- PRTG Network Monitor
- Zabbix
- Net-SNMP
- Other SNMP-compatible Network Management Systems (NMS)

Platform-specific integration resources are maintained separately when available.
